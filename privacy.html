プライバシーポリシー

kasoscope-upload(以下「本ツール」)は、運営者本人が自分の YouTube チャンネルを管理するための個人用ツールです。

取得する情報

運営者本人の Google アカウントの承認を通じて、YouTube チャンネルの情報(チャンネルID・名称)、および本人が投稿する動画の公開設定を扱います。

利用目的

動画のアップロードと公開予約の設定にのみ使用します。

保管と共有

認証情報は、運営者本人のパソコン内にのみ保存します。第三者への提供、販売、広告利用はしません。外部のサーバーへ送信・保存することもありません。

Google API サービスのユーザーデータの取り扱い

本ツールによる Google API から受け取った情報の使用および他のアプリへの移転は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

データの削除

運営者は、Google アカウントの設定から、いつでも本ツールのアクセス権を取り消せます。
